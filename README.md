Your Bank - Front-End Website
Overview
Your Bank is a responsive front-end website designed by Mouliarasu S, a B.Sc. Computer Science graduate from Bharathidasan University. This project showcases a modern banking interface with a clean design, built using HTML, CSS, and JavaScript. It demonstrates skills in web development, responsive design, and user interaction.
Features
Navigation Bar: Responsive hamburger menu for mobile devices.

Hero Section: Welcoming banner with a call-to-action button.

About Me: Highlights Mouliarasu S’s background and passion for web development.

Services: Displays banking services (Savings, Online Banking, Loans) in card format.

Contact Form: Interactive form with basic client-side validation.

Smooth Scrolling: Seamless navigation between sections.

Responsive Design: Optimized for both desktop and mobile devices.

Technologies Used
HTML5: Structure and content.

CSS3: Styling, flexbox, and media queries for responsiveness.

JavaScript: Interactivity (hamburger menu, form handling, smooth scrolling).

Setup Instructions
Clone the repository: git clone <repository-url>

Open index.html in a web browser or use a local server (e.g., VS Code Live Server).

Ensure style.css and script.js are in the same directory.

Notes
The hero section references a placeholder bank-bg.jpg. Replace it with a banking-related image or modify the CSS for a gradient background.

The contact form logs data to the console. For production, integrate a backend to handle submissions.
